# 🚀 Mohamed Atef - Personal Portfolio

A modern, responsive, and fully localized personal portfolio application built with React, TypeScript, and Framer Motion.

## ✨ Features
- 🌐 **Multi-language Support (i18n):** Toggle seamlessly between English and Arabic with full RTL support.
- 🌓 **Dark / Light Mode:** Custom theme context switching.
- 📱 **Fully Responsive:** Optimized for desktop, tablet, and mobile devices.
- 📧 **Interactive Contact Form:** Powered by EmailJS with real-time response feedback.
- 🎨 **Animations:** Fluid animations using Framer Motion and Lottie.

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Vite
- **Styling:** CSS3, Material UI, SASS
- **Localization:** i18next, i18next-browser-languagedetector
- **Animations:** Framer Motion, Lottie-React
- **Icons:** Lucide React, React Icons
- **Email Service:** EmailJS
